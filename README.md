# WoodEx — Студія авторських виробів з дерева

**WoodEx** — це преміальний інтернет-магазин та платформа авторських дерев’яних виробів ручної роботи (освітлення, різьблення, меблі) та цифрових товарів (3D-моделі STL/OBJ для ЧПУ, векторні макети SVG/DXF).

## 🪵 Особливості проекту

- 🌲 **Ексклюзивний дизайн**: темна тепла палітра, золоті акценти, ефект матового скла (glassmorphism), шрифти Cormorant Garamond та Inter.
- 🌐 **Мультимовність**: повна підтримка української (`uk`) та англійської (`en`) мов через `next-intl`.
- 🛍️ **E-commerce функціонал**:
  - Каталог фізичних виробів з фільтрацією та галереями
  - Цифровий маркетплейс з миттєвим доступом до завантаження
  - Кошик та інтерактивна форма оформлення індивідуального замовлення
  - Особистий кабінет клієнта (історія замовлень, цифрові завантаження)
- ⚡ **Стек технологій**: Next.js 14 (App Router), TypeScript, Vanilla CSS Modules, Next-Intl.

## 🚀 Запуск проекту

1. **Встановлення залежностей**:
   ```bash
   npm install
   ```

2. **Збірка проекту**:
   ```bash
   npm run build
   ```

3. **Запуск**:
   ```bash
   npm start
   # або для режиму розробки:
   npm run dev
   ```

4. Відкрийте у браузері [http://localhost:3000](http://localhost:3000).
